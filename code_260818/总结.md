## 知识点整理

### 1. 类和对象

- **类**：用户自定义的数据类型，包含成员变量和成员函数
- **对象**：类的实例
- **访问权限**：
  - `public`：外部可访问
  - `private`：仅类内部可访问（默认）
  - `protected`：类内部和派生类可访问

```cpp
class Student {
private:
    string name;
    int age;
public:
    void setName(string n) { name = n; }
    string getName() { return name; }
};

Student s;  // 创建对象
s.setName("张三");
```

### 2. 构造函数

- 与类名相同，无返回类型
- 创建对象时自动调用
- 用于初始化成员变量

```cpp
class Student {
private:
    string name;
    int age;
public:
    // 默认构造函数
    Student() { name = ""; age = 0; }

    // 带参构造函数
    Student(string n, int a) { name = n; age = a; }
};

Student s1;              // 调用默认构造
Student s2("张三", 20);   // 调用带参构造
```

> ⚠️ **陷阱**：一旦定义了**任何**构造函数，编译器就不再自动生成默认构造函数（mooc008 踩过）。需要 `A a;` 这种写法时，必须显式补上 `A() {}`。

### 3. 拷贝构造函数

- 参数是本类对象的引用（通常用 `const` 修饰）
- 用于用一个对象初始化另一个对象
- 如果不显式定义，编译器会自动生成默认拷贝构造函数（浅拷贝）

```cpp
class Student {
private:
    string name;
    int age;
public:
    Student(string n, int a) { name = n; age = a; }

    // 拷贝构造函数
    Student(const Student &other) {
        name = other.name;
        age = other.age;
    }
};

Student s1("张三", 20);
Student s2(s1);  // 调用拷贝构造函数
```

> 💡 拷贝构造函数会在 **3 种情况**被调用：
> 1. `Student s2(s1);` 或 `Student s2 = s1;`（用一个对象初始化另一个对象）
> 2. **函数传参按值**：`void f(Student o)`，`f(s1)` 时形参 o 是 s1 的拷贝
> 3. **函数返回对象**（按值返回时）
> 注意：**赋值** `s2 = s1;`（对象已存在）调用的是赋值运算符，不是拷贝构造！

### 4. 析构函数

- 函数名：`~类名()`
- 无参数，无返回类型
- 对象销毁时自动调用
- 用于释放资源（如动态分配的内存）

```cpp
class Student {
private:
    int *score;
public:
    Student() { score = new int(0); }

    // 析构函数
    ~Student() {
        delete score;  // 释放动态分配的内存
    }
};
```

> 💡 **`delete` 空指针是安全的**（空操作，不崩溃），所以 `delete p` 前不需要判空。但 **`new` 必须配 `delete`，`new[]` 必须配 `delete[]`**，混用是未定义行为（mooc004）。

### 5. 引用专题（今日重点）

**引用（`&`）就是变量的别名**，操作引用就是操作原变量本身。核心用途：作参数、作返回值。

#### 5.1 引用作参数（mooc001、mooc002）

按值传参会复制副本，改不动原变量；传引用才能真的修改：

```cpp
// 普通变量传引用：交换对象成员（mooc001）
void swap(A &a, A &b) {
    int tmp = a.x;
    a.x = b.x;
    b.x = tmp;
}

// 指针的引用：交换指针本身（mooc002）
void swap(int * &a, int * &b) {   // 形参是指针变量的引用
    int *tmp = a;
    a = b;
    b = tmp;
}
```

mooc002 里如果写成 `void swap(int *a, int *b)`，交换的只是两个形参指针副本，`pa`/`pb` 不变——和经典 `swap` 写错是同一个坑，指针本身也是变量。

#### 5.2 引用作返回值：左值化（mooc003）

函数返回引用，调用结果可以当**左值**（可写）使用：

```cpp
int & getElement(int *a, int i) {
    return a[i];          // 返回数组元素的引用
}

getElement(a, 1) = 10;    // 等价于 a[1] = 10，直接写入数组
cout << a[1];             // 输出 10
```

如果返回 `int`（值），`getElement(a, 1) = 10;` 就是改临时副本，编译直接报错。

#### 5.3 返回 `*this`：链式操作（mooc007）

成员函数内 `this` 是指向调用对象的指针，`*this` 就是对象自身。返回 `*this` 的引用，就能对返回值继续赋值/操作：

```cpp
class A {
public:
    int val;
    A& GetObj() { return *this; }   // 返回自己的引用
    A(int i) { val = i; }
    A() { val = 123; }
};

a.GetObj() = 5;   // GetObj() 返回 a 自身的引用，= 5 直接写进 a.val
```

**引用返回 vs 值返回对比**：

| 返回方式 | 返回的是 | `f() = x` 的效果 | 风险 |
| --- | --- | --- | --- |
| `A f()` | 临时副本 | 修改副本，原对象不变（编译可能过但逻辑错） | 无 |
| `A& f()` 返回 `*this` | 对象自身 | 直接修改原对象 ✅ | 无 |
| `A& f()` 返回局部变量 | 已销毁对象的引用 | 悬垂引用，未定义行为 ❌ | **悬垂引用** |

### 6. 初始化 vs 赋值（mooc006）

**一句话：初始化 = 对象"出生"（构造），赋值 = 对象已存在后"改名"（`operator=`）**，两者完全不同。

```cpp
Sample a(5);
Sample b = a;   // ① b 还不存在 → 拷贝构造（出生）
Sample d;       // ② d 不存在 → 默认构造
d = a;          // ③ d 已存在 → 拷贝赋值运算符 operator=（编译器自动生成）
```

```cpp
class Sample {
public:
    int v;
    Sample(int x) { v = x; }
    Sample() { v = 0; }
    Sample(const Sample &s) { v = s.v + 2; }  // 拷贝构造 +2
};
```

| 写法 | 调用什么 | 是否 +2 |
| --- | --- | --- |
| `Sample b = a;`（同类型初始化） | 拷贝构造 | 是（s.v+2）|
| `Sample c = 20;`（不同类型初始化） | `Sample(int)` 转换构造 | 否 |
| `PrintAndDouble(b)`（传参按值） | 拷贝构造（形参）| 是 |
| `d = a;`（已存在对象） | 拷贝赋值 `operator=` | 否（原样复制）|

判断口诀：**看等号左边的对象是不是第一次出现**——是则构造，否则赋值。

### 7. 拷贝省略（copy elision）（mooc006）

```cpp
Sample c = 20;   // 只调用一次 Sample(int)，不调用拷贝构造
```

虽然理论上"先构造临时对象、再拷贝给 c"也合法，但 **C++17 起标准强制省略这次拷贝**（早期编译器也都会优化掉）。所以 `Sample c = 20;` 最终只调用一次 `Sample(int)`——本题的拷贝构造有 `+2` 的副作用，如果没省略，结果就错了。

> 引申：现代 C++ 里 `T x = f();` 这种"先临时再拷贝"的担心大多不必要，编译器保证零拷贝。

### 8. 指针数组与判空（mooc004）

```cpp
int *a[] = {NULL, new int(2), new int(3), new int[10]};

if (!a[0]) { ... }   // !a[0]：a[0] 是空指针(NULL=0)，!0 = true，判空写法
```

- `NULL` 的值为 0，作为布尔值即 `false`，所以 `!ptr` 就是"指针为空"，等价于 `ptr == NULL`
- 释放时**一一配对**：`a[0]~a[2]` 是 `new` 出来的 → `delete`；`a[3]` 是 `new[]` → `delete[]`
- `delete` 空指针（如 `a[0]`）安全无操作，可放心写

### 9. 字符串处理（mooc005 等）

#### 9.1 `getline()` 按分隔符分割

```cpp
string line = "小明,20,2026001,90.5,85,92,88";
stringstream ss(line);
string step;
getline(ss, step, ',');   // step = "小明"（读到逗号停止，逗号被消耗掉）
getline(ss, step, ',');   // step = "20"
```

`getline` 的第三个参数指定分隔符，是**手写字符串分割的最简方案**，比 `find` + `substr` 循环直观得多。

#### 9.2 `stod()` 函数

- 功能：将 `string` 转换为 `double`（`stoi()` 转 int，同理）
- 头文件：`<string>`
- C++11 标准，使用方便

```cpp
string str = "3.14";
double val = stod(str);  // val = 3.14
```

#### 9.3 `strtod()` 函数（C 风格）

- 功能：将 `const char*` 转换为 `double`
- 头文件：`<cstdlib>`
- 优势：可以检测转换后的剩余字符

```cpp
const char *str = "3.14abc";
char *end;
double val = strtod(str, &end);  // val = 3.14，end 指向 "abc"
```

#### 9.4 `stringstream` 类

- 功能：字符串流，可用于字符串与其他类型的转换
- 头文件：`<sstream>`

```cpp
// 字符串转数字
string str = "123";
stringstream ss(str);
int num;
ss >> num;  // num = 123

// 数字转字符串
int n = 456;
stringstream ss;
ss << n;
string str = ss.str();  // str = "456"

// 分割字符串（配合 getline）
string s = "hello,world,2026";
stringstream ss(s);
string token;
while (getline(ss, token, ',')) {
    cout << token << endl;
}
```

### 10. 深拷贝与浅拷贝

**浅拷贝**：
- 默认拷贝构造函数执行的就是浅拷贝
- 逐个复制成员变量的值（按位复制）
- 如果成员中有指针，只复制指针的地址，不复制指针指向的内容
- 结果：两个对象的指针指向同一块内存

**深拷贝**：
- 需要自定义拷贝构造函数
- 不仅复制指针，还为指针指向的内容重新分配内存并复制数据
- 结果：两个对象各自拥有独立的内存

**深拷贝的作用**：
- 避免多个对象共享同一块内存导致的**重复释放**问题（程序崩溃）
- 避免一个对象修改数据影响到另一个对象
- 当类中有动态分配的资源（如 `new` 分配的内存）时，必须实现深拷贝

**浅拷贝问题示例**：
```cpp
class Student {
private:
    int *score;
public:
    Student(int s) { score = new int(s); }
    ~Student() { delete score; }
    // 没有自定义拷贝构造函数 → 默认浅拷贝
};

Student s1(90);
Student s2(s1);  // 浅拷贝：s1.score 和 s2.score 指向同一块内存
// 程序结束时，s1 和 s2 的析构函数各 delete 一次 → 崩溃！
```

**深拷贝正确写法**：
```cpp
class Student {
private:
    int *score;
public:
    Student(int s) { score = new int(s); }

    // 自定义拷贝构造函数（深拷贝）
    Student(const Student &other) {
        score = new int(*(other.score));  // 重新分配内存并复制值
    }

    ~Student() { delete score; }
};

Student s1(90);
Student s2(s1);  // 深拷贝：s1 和 s2 各自拥有独立的内存
// 程序结束时，各自 delete 自己的内存 → 正常
```

**对比总结**：

| 对比项 | 浅拷贝 | 深拷贝 |
| --- | --- | --- |
| 实现方式 | 编译器默认生成 | 需要自定义拷贝构造函数 |
| 指针成员 | 只复制地址 | 重新分配内存并复制数据 |
| 内存安全 | 可能重复释放导致崩溃 | 各自独立，安全 |
| 适用场景 | 类中无动态资源 | 类中有 `new` 分配的动态资源 |

## 常见陷阱清单（今日踩坑汇总）

| # | 陷阱 | 现象 | 正确做法 |
| --- | --- | --- | --- |
| 1 | **Most Vexing Parse**：`A b();` | 编译器理解为"函数声明"而非"创建对象"，编译报错 | 写 `A b;` 或 `A b{};` |
| 2 | **返回局部变量的引用** | 悬垂引用，运行时未定义行为 | 返回 `*this`、成员或堆上对象 |
| 3 | **构造函数里 `return *this;`** | 构造函数不允许返回值，编译报错 | 删掉 return 语句 |
| 4 | **定义了带参构造后，默认构造消失** | `A a;` 编译报错 | 显式补 `A() {}` 并初始化所有成员 |
| 5 | **隐式转换链只允许一次用户自定义转换** | `a = "3+4i"` 需要 `const char*→string→Complex` 两次转换，编译失败 | 显式写 `Complex& operator=(const string&)` |
| 6 | **读取未初始化的成员变量** | `v = v + 2;` 中 v 是垃圾值，未定义行为 | 构造函数里把所有成员初始化 |
| 7 | **`new` / `delete[]` 混用** | 释放方式不配对，未定义行为 | `new`↔`delete`，`new[]`↔`delete[]` |
| 8 | **形参传值/返回值把拷贝构造触发** | 传参按值、返回对象都会调用拷贝构造函数（可能带来额外开销或副作用） | 不需要修改就传 `const &` |

## 常用转换方法对比

| 方法 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| `strtod()` | `const char*` | `double` | C风格，可检测剩余字符 |
| `stod()` | `string` | `double` | C++风格，简单方便 |
| `stringstream` | `string` | 任意类型 | 灵活，支持多种类型转换 |

## 调试经验（VSCode）

- **断点不生效**：确认点的是 🐞 调试（F5），不是 ▶ 运行（▶ 会忽略所有断点）
- **断点空心圆**：源码和正在调试的可执行文件对不上（比如调试配置写死了旧目录/旧 exe 路径，或没带 `-g` 编译）
- 编译参数要带 `-g` 才有调试符号；`launch.json` 里 `program` 应指向当前文件的 exe
- **程序看起来"卡死"**：可能不是卡死，是在 `getline(cin, ...)` 等键盘输入，往终端输入数据即可
