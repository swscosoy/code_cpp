## 知识点整理

### 1. 深拷贝（mooc014）

**浅拷贝问题**：指针成员被默认拷贝构造/赋值复制的是"地址"而非"内容"，两个对象指向同一块内存 → 析构时对同一块内存 `delete` 两次（double free）。

```cpp
MyString(const MyString &s) {          // 拷贝构造：深拷贝
    if (s.p) {
        p = new char[strlen(s.p) + 1];
        strcpy(p, s.p);
    } else
        p = NULL;
}
MyString &operator=(MyString &s) {     // 赋值运算符：先释放旧的，再深拷贝
    if (s.p) {
        delete[] p;
        p = new char[strlen(s.p) + 1];
        strcpy(p, s.p);
    } else
        p = NULL;
    return *this;
}
void Copy(const char *s) { ... }       // 额外接口，与 operator= 逻辑类似
```

要点：

- **凡是有 `new` 出来的指针成员，三件套（拷贝构造/赋值/析构）要配套**：浅拷贝 + 析构必炸
- 赋值运算符比拷贝构造多了**先 `delete[]` 旧内存**的步骤（对象已经存在）
- 时刻检查 `p == NULL` 的分支，防止 `strlen(NULL)` 段错误

### 2. 类型转换运算符 + 链式运算（mooc015）

```cpp
operator int() { return nVal; }        // ★ 转换运算符：无返回类型（返回类型就是 int）

MyInt &operator-(int a) {              // ★ 返回引用：支持 objInt-2-1-3 链式
    nVal -= a;
    return *this;
}
// 用法：Inc(objInt) —— objInt 隐式转换为 int 传入函数
```

要点：

- **转换运算符写法**：`operator 目标类型()`，**不写返回类型**，参数为空，`int` 就是要转成的类型
- **链式运算必须返回引用**（`MyInt&`）：`objInt-2-1-3` 等价于 `((objInt-2)-1)-3`，每次减完返回自身才能继续减
- 用途：让对象在需要 `int` 的地方（函数实参、赋值、运算）被自动转换

### 3. 友元重载流运算符（mooc016）

```cpp
friend istream &operator>>(istream &cin, Point &s);   // 声明为友元才能访问 x, y
friend ostream &operator<<(ostream &cout, Point &s);

ostream &operator<<(ostream &cout, Point &s) { cout << s.x << "," << s.y; return cout; }
istream &operator>>(istream &cin, Point &s)  { cin >> s.x >> s.y;  return cin; }
```

要点：

- **为什么必须友元/全局函数**：`<<` 的左操作数是 `ostream` 对象，不是本类对象，不能写成成员函数（成员函数的左操作数必须是本类）
- **参数和返回值都要是引用**：`istream&` / `ostream&` 引用返回才能支持 `cin >> a >> b` 链式
- 形参名写 `cin`/`cout` 只是遮蔽全局名字，不影响功能

### 4. 运算符重载全家桶（mooc019）

| 运算符 | 形式 | 关键点 |
| --- | --- | --- |
| `+` | 成员 `operator+(const MyString&)` + 全局两个版本（`char*+s`、`s+char*`）| 字符串在左边时不能是成员函数，全局重载 |
| `+=` | 成员 `void operator+=(const char*)` | 用临时对象 + 赋值组合实现 |
| `=` | 成员 `MyString&`，两种参数（MyString、char*）| 返回引用支持链式 `a = b = c` |
| `[]` | 成员 `char& operator[](int)` | **返回引用才能写**：`s1[2] = 'A'` |
| `< > ==` | 成员 `bool`，内部用 `strcmp` | 供 qsort 比较用 |
| `()` | 成员 `MyString operator()(int n, int m)` | 当"取子串"用：`s1(0,4)` 取下标 0 起 4 个字符 |
| `<<` | 友元全局 `ostream&` | 左操作数不是本类 → 友元 |

**为什么 `[]` 必须返回引用**（`char&` 而不是 `char`）：

```cpp
char &operator[](int a) { return this->p[a]; }   // ✅ 返回引用
// char  operator[](int a) { return this->p[a]; }  // ❌ 按值返回
```

- 题目要求 `s1[2] = 'A'` 能**写**字符串，`s1[2]` 必须是一个可赋值的左值
- 返回 `char`（按值）得到的是临时量（右值），给右值赋值**非法**，编译报错：`lvalue required as left operand of assignment`
- 返回 `char&` 后，`s1[2]` 就是 `p[2]` 那块内存本身——既当左值可写（`s1[2] = 'A'`），也能读值（`cout << s1[2]`）

**qsort 回调**（C 风格函数指针）：

```cpp
int CompareString(const void *e1, const void *e2) {
    MyString *s1 = (MyString *)e1;   // const void* 强转回具体类型
    ...
    return -1/0/1;                   // 三态返回：小于/等于/大于
}

```

### 5. 继承与派生（课程内容）

**基本语法**：派生类在基类基础上扩展，"包含"基类的全部成员 + 自己的新成员。

```cpp
class Base { ... };
class Derived : public Base { ... };   // 继承方式：public / protected / private
```

要点（本课核心）：

- **三种继承方式**（基类成员在派生类中的访问权限）：

  | 基类成员 | public 继承 | protected 继承 | private 继承 |
  | --- | --- | --- | --- |
  | public | public | protected | private |
  | protected | protected | protected | private |
  | private | 不可访问 | 不可访问 | 不可访问 |

- **protected 访问权限**：类内和派生类内可访问，外部不可访问（介于 public / private 之间）
- **构造/析构顺序**：构造时**先基类后派生类**（先有爸爸再有儿子）；析构相反，**先派生类后基类**
- **基类构造函数的调用**：派生类构造函数通过**初始化列表**调基类构造函数：

  ```cpp
  class Base { public: Base(int n) {...} };   // 没有默认构造
  class Derived : public Base {
  public:
      Derived(int a, int b) : Base(a) {...}   // 必须在初始化列表给基类传参
  };
  ```

- **同名遮蔽**：派生类定义与基类同名成员时，隐藏基类成员；用 `基类名::成员名` 访问被遮蔽的基类成员
- **赋值兼容规则**（仅公有继承）：派生类对象可以赋值给基类对象、可以初始化基类引用、可以用基类指针指向派生类对象（"儿子可以当爸爸用"，反之不行）
- **继承与复合**：继承是 is-a 关系（圆是图形），复合/成员对象是 has-a 关系（车有引擎）
- 简单了解：多层继承（A ← B ← C）、多继承（一个类有多个基类）

## 调试经验

- **"control reaches end of non-void function"** 的检查顺序：① 函数是否所有分支都有 return；② if/else if 链是否漏了兜底；③ 函数最后一行是否真的"可达"（死代码也算）
- **OJ 报重复定义（redefinition）先想提交内容**：报错里如果函数名在模板里本来就有（main、qsort 回调、全局函数），八成是填空/补全型题目提交了整个文件——**看报错行的行号对比，205 行（模板自带）vs 218 行（你的）**
- **本地能跑 ≠ OJ 能编译**（延续昨天）：除了 C++ 标准差异，还要注意提交**内容边界**问题
