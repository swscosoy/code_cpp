## 知识点整理

### 1. 引用（Reference）

- 符号：`&`
- 引用是变量的别名，必须在定义时初始化，且不能重新绑定
- 引用不占用额外内存（与指针不同）
- **引用的本质**：引用本质上是一个**指针常量**（`T *const`），即指向不可变的指针。编译器在底层通过指针实现引用，但限制了指针的指向不可更改，所以引用一旦绑定就不能重新绑定到其他变量

```cpp
int a = 10;
int &ref = a;  // ref 是 a 的引用
ref = 20;      // a 也变为 20
```

### 2. const 关键词

- `const` 修饰变量：变量值不可修改，定义时必须初始化
- `const` 修饰指针：区分常量指针和指针常量
- `const` 修饰函数参数：防止函数内部修改参数
- `const` 修饰成员函数：表示该函数不修改成员变量

```cpp
const int x = 10;        // x 不可修改
int *const p = &a;       // 指针常量：指针指向不可变，内容可变
const int *p = &a;       // 常量指针：内容不可变，指针指向可变
void func(const int &x); // 参数引用，不可修改
```

### 2.1 const 引用（今日重点）

- **绑定规则：权限只能缩小，不能扩大**
  - ✅ `const int &m1 = b;`（b 是普通引用）——正确，const 引用可以绑定普通引用
  - ❌ `int &c = m1;`（m1 是 const 引用）——错误，普通引用不能绑定 const 引用，否则会绕过 const 限制修改值

- **关键理解：const 引用 ≠ 变量变成常量**
  - `const int &m1 = b;` 的含义是"**通过 m1 这条路径不能修改**"，而不是"b/a 本身不能修改"
  - const 限制的是"用哪条路改"，不是"东西本身不能改"
  - 其他非 const 路径（如 b）仍可修改，修改后 const 引用也能"看到"新值

```cpp
int a = 1;
int &b = a;
const int &m1 = b;
m1 = 2;       // ❌ 错误：不能通过 const 引用修改
b = 3;        // ✅ 正确：b 是普通引用，可以修改
cout << m1;   // 输出 3：m1 和 b 指向同一个 a
```

### 3. 动态内存分配

- 分配：`new`
- 释放：`delete`
- 数组分配：`new[]`，释放：`delete[]`
- 忘记释放会导致**内存泄漏**

```cpp
int *p = new int(10);     // 分配单个 int，初始值为 10
delete p;                  // 释放

int *arr = new int[100];   // 分配 100 个 int 的数组
delete[] arr;              // 释放数组
```

### 4. 内联函数（Inline Function）

- 关键字：`inline`
- 作用：在编译时将函数体直接嵌入调用处，减少函数调用开销
- 适用场景：代码量小、频繁调用的函数
- 注意：编译器不一定真正内联，复杂函数会被忽略

```cpp
inline int add(int a, int b) {
    return a + b;
}
// 调用 add(1, 2) 时，编译器会替换为 1 + 2
```

### 5. 重载函数（Overload）

- 同一作用域内，函数名相同，但参数列表（个数、类型、顺序）不同
- 返回值类型**不能**作为重载的依据
- 编译器根据实参匹配对应的重载版本

```cpp
int add(int a, int b) {
    return a + b;
}
double add(double a, double b) {
    return a + b;
}
int add(int a, int b, int c) {
    return a + b + c;
}
```

### 6. Git 基本流程

| 命令 | 作用 |
| --- | --- |
| `git add <文件>` | 将修改添加到暂存区 |
| `git commit -m "说明"` | 将暂存区内容提交到本地仓库 |
| `git push` | 将本地提交推送到远程仓库 |
| `git pull` | 从远程仓库拉取最新代码并合并 |

- 网络问题时需要配置 SSH 密钥来连接远程仓库（如 GitHub/Gitee）
